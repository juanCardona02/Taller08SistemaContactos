# Taller08SistemaContactos

CRUD de sistema de contactos.

## Ejecución

1. Corres el script de MySQL.
2. Instalar nmp en el front.
3. En el Backend en el directorio Resources en el fichero application.propiertes, en la linea de código (spring.datasource.username=username), en uusername tiene que colocar el usuario de la base de datos, que en este caso se trabaja con MySQL, y en  la linea de código (spring.datasource.password=password), en password  tiene que colocar la contraseña de la base de datos.  
4. Inciar los servidores del frontend y del backend.
